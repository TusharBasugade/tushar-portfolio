Projects

Weather Forecasting Website

Originally built with HTML, CSS, and JavaScript, this Weather Prediction App has since been rebuilt in React.js with a modular, scalable architecture using Redux for state management. It fetches real-time weather data via the OpenWeatherMap API, offering current-location detection, city-specific search, and a voice-readout feature, along with a favorites system for saving preferred locations. Organized into reusable components, custom hooks, and dedicated service layers, the app delivers a responsive, seamless experience across all devices.

Stock Portfolio Dashboard

A Power BI dashboard built to analyze personal stock holdings and trading performance using CSV data on holdings, historical prices, and PnL. The project involved data cleaning, modeling, custom DAX measures, and a date table, structured across two pages — one for live current holdings with KPIs and charts, and another for historical performance over time. The dashboard is designed to fetch live stock data via API for auto-updating insights.

Skin Cancer Detection Using Deep learning

Developed a deep learning-based web application for skin lesion detection and classification (e.g., melanoma) using the HAM10000 dataset. The application leverages EfficientNet (CNN) for high-accuracy image classification and features a user-friendly Streamlit interface that allows users to upload lesion images and receive predictions. It also generates downloadable PDF reports and recommends nearby hospitals based on the user's location, providing a comprehensive diagnostic support experience.
